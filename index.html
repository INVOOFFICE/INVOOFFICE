Tout ce que vous devez savoir sur INVOO OFFICE.

Oui, absolument. INVOO OFFICE est une PWA (Progressive Web App) qui fonctionne 100% hors ligne grâce au stockage OPFS (Origin Private File System) de votre navigateur. Vous pouvez créer, modifier et consulter toutes vos factures même sans connexion internet.

Oui, INVOO OFFICE est entièrement conforme aux exigences de la Direction Générale des Impôts du Maroc. Toutes les factures incluent automatiquement les mentions obligatoires : TVA, ICE, IF, RC, et autres informations fiscales requises.

Oui, INVOO OFFICE est entièrement responsive et fonctionne parfaitement sur mobile, tablette et PC. Vous pouvez même l'installer comme une application native sur votre téléphone depuis votre navigateur.

Vos données sont stockées localement dans votre navigateur via l'API OPFS (Origin Private File System). Elles ne quittent jamais votre appareil sauf si vous choisissez explicitement d'activer la synchronisation cloud optionnelle.

Oui, vous pouvez exporter l'intégralité de vos données à tout moment sous forme de fichier JSON portable. Cette sauvegarde peut être stockée sur votre ordinateur, une clé USB ou tout service de cloud de votre choix.

Oui, via la synchronisation optionnelle avec Supabase. Cette fonctionnalité vous permet de synchroniser vos données entre plusieurs appareils (mobile, tablette, PC) de manière sécurisée. Elle est totalement optionnelle et désactivée par défaut.
